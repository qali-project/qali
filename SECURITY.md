# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately to the maintainers. Do not open a
public issue, pull request, or discussion for a suspected vulnerability.

Until the project's hosted repository is published, contact the maintainer
directly. After publication, use the repository's private vulnerability
reporting feature. This file will name the exact channel at that point.

Include affected version or commit, configuration, reproduction steps, and the
impact you observed. Never include real credentials or personal data.

## Supported versions

Qali has no release yet. Before the first release, only the latest commit on
the default branch receives fixes. A supported-version table and patch SLA are
published with the MVP release (MVP-15).
