# Architecture Decision Records

Decisions that change migrations, API shapes, credential models, or role
behavior are recorded here. New records start from [the template](TEMPLATE.md),
take the next free number, and are added to this index in the same change.

Allowed statuses: `Proposed`, `Accepted`, `Deprecated`, and
`Superseded by ADR-NNNN`. A `Proposed` record becomes `Accepted` after
maintainer review; MVP-00 completes only when its records are accepted.
